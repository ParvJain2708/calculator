# 🧮 Simple Calculator (Java Swing)

## 📘 Project Overview
This is a **simple calculator application** built using **Java Swing**.  
It performs basic arithmetic operations — addition, subtraction, multiplication, and division — through a graphical user interface (GUI).

---

## 🚀 Features
- Perform basic arithmetic operations: `+`, `-`, `*`, `/`
- Clear and simple interface
- Handles decimal numbers
- Responsive button actions
- Error-free and easy to use

---

## 🧩 Technologies Used
- **Java**
- **Swing** (for GUI components)
- **AWT** (for layouts and event handling)
